# 第八关 · 贤者与第七关修正

第八关开局前介绍紫、华扇、摩多罗和蓝四张可移动的更新卡牌，沿用阵营色光晕与旧卡焕新动画。舞与里乃仍留给玩家在香霖堂探索。简介与三个目标均支持中英文。

## 第八关开局与技能

- 中级 AI、两人对局，先手随机。双方各六张随机起手；玩家必有摩多罗及另一张贤者牌，以交换牌堆中的原卡保证条件，不额外增加手牌。
- 仍在抽牌堆中的贤者原卡放入接下来的五次抽牌范围；不移动已经发到双方手里的牌。
- 开放红魔馆、白玉楼、永远亭、妖怪之山、地灵殿及贤者技能。其他阵营继续使用已有的无技能外观与占位说明。
- 香霖堂固定包含“丁礼田舞与尔子田里乃”这张组合卡；其余两个商品从已开放阵营的第五张卡中随机选取，商店内无重复牌。
- AI 不读取玩家起始手牌。未加入额外的第八关教学，第一、三、六关已有的可跳过教学保留。

## 三星判定

胜利是通关与保存星星的前提，不占用额外目标名额。星星按现有规则在多次胜利中累计，一局完成全部目标则显示贤者阵营色。

| 目标 | 判定 |
| --- | --- |
| 收取贤者阵营 | 玩家实际完整收取四张贤者阵营牌。 |
| 使一个被收取的阵营只有一种卡牌 | 玩家实际完整收取一个二卡阵营，收取前两张牌的原型 ID 相同；原卡与摩多罗创造的同原型卡可以满足。普通的两种角色组合、对手的收取、四卡阵营的同原型组合不满足。 |
| 放置同一张卡两次 | 只统计玩家成功放上棋盘的实体 ID。被紫收回、被燐挖回后重放仍是同一张牌；不同复制牌各放一次不算。移动、交换位置、只查看落点、失败放置和重复技能结算均不会增加次数。自动入场按其持有者记录。 |

四卡收取仍使用现有结算顺序、弃牌与胜利规则，没有为目标伪造分数或发牌。

## 第七关 AI、提示与永琳立绘

第七关中级 AI 在主动选择落点时排除古明地恋；若双方弃牌区都为空，也排除当前技能为燐回收能力的牌。任意一方弃牌区出现牌后，燐重新进入正常评估。过滤也覆盖交易后的主动跟进放置。人类可选操作、其他关卡与普通模式不受影响，铃仙强制放置与恋的自动入场仍按共同规则执行。

提示改为：**玛丽小姐在手牌里可是很贪玩的呢，也许把她放到另一个地方就可以解决这个问题？**

永琳保留此前放大的比例，在缩略卡面下移 6px，在详情卡下移立绘高度的 6%。背景、图标与文字布局不变。
