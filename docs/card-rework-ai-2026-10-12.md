# 本次卡牌规则与 AI 调整说明

本版以你的实战反馈为准。美铃的技能没有加强；第五张阵营卡的主要价值仍是增加可收取该阵营的机会。旧版 1500 局的数据用于诊断旧规则与旧 AI，不能直接证明重制后的卡牌强度。

## 已实现的规则

| 卡牌 | 本版行为 | 关键细节 |
|---|---|---|
| 永琳 | 放置时创造一张永远亭卡牌（永琳除外），并立刻打出；在场时禁用所有贤者能力 | 不再封锁其他阵营的领主；华扇的替代身份、紫的覆盖、蓝的抽牌等贤者能力也受禁用。 |
| 文 | 自己阅读报纸；他人付一张手牌给文的玩家后才能阅读 | 付款进入文的玩家手牌，不进入抽牌堆。每一期分别订阅；已购买该期无需重复付款。报纸记录发表时的情报，后续手牌变化不会自动更新它。 |
| 觉 | 随机展示目标手牌中的四张，之后可取任意一张 | 少于四张则全部展示。未展示的卡仍可拖动、选择、确认，使用现有选牌桌面；它们显示背面并使用匿名标识。 |
| 燐 | 取回弃牌后，把取回卡的技能改成“覆盖：放置时抽一张牌” | 原有阵营保留，改写持续到本局结束；不能再次使用原来的强力技能。取回牌具有破旧外观。 |
| 摩多罗 | 从棋盘卡牌中创造一张复制卡（摩多罗除外），并赋予复制卡双倍能力 | 复制卡进入手牌，等待以后打出；原卡仍在棋盘。受现有不可选中保护的卡不能作为目标。 |
| 华扇 | 保留四卡阵营替代规则，调整提前放置的 AI 判断 | 不替代两卡阵营。AI 可以为自己的四卡阵营提前铺设，也会考虑被别人收走的风险。 |
| 久侘歌 | 荒地上放置时从牌堆拿一张地狱牌；普通位置放置时把正交邻格变荒地 | 边角只处理存在的邻格；变荒地不会删除已经站在这些位置上的卡。 |
| 鵺 | 说明文字移除“短暂变为该卡牌的外貌” | 仍从三张随机卡的能力中选择并使用一个。 |
| 水蜜 | 自己接下来一回合不能放置或交易；选定玩家接下来两回合不能放置或交易 | 仍可合法抽牌。若选择自己，则两回合限制覆盖一回合限制，不相加成三回合。额外回合也按现有回合流程扣减限制。 |

## “创造”的执行口径

创造从指定类型的候选中随机提供至多三张不同卡牌，选择一张，把它的复制加入手牌。复制有独立编号，原卡不移动。同名原卡与复制卡可以同时存在于不同区域。

永琳从永远亭的原始卡种中抽选，排除永琳，包括该阵营第五张卡。摩多罗从当前可选择的棋盘卡实例中抽选，排除所有摩多罗实例，复制实例当前的能力。因此，摩多罗复制被燐改写的卡，得到的也是“覆盖：放置时抽一张牌”，而不是被改写前的技能。自身限制按原始角色身份判断，已有复制卡也不能绕过限制。

技能代价增加一张；原来无代价的技能也需要付一张才能发动。代价仍可拒付，复制卡的本体可以正常留在棋盘。再次创造已有的复制卡时，额外代价继续累积。

| 原能力 | 复制后 |
|---|---|
| 无代价的抽一张牌 | 支付一张，再抽一张。 |
| 觉的代价 I | 代价 II。 |
| 幽幽子的代价 N | 支付 N+1 张，效果仍处理 N 个目标。没有额外的 Cost I 限制。 |
| 白莲的可减免代价 | 先按阵营减免原代价，再增加复制卡的额外代价；减免不能抹掉这项额外代价。 |

本次对“双倍能力”的实施解释是：主动能力结算两次，两次分别决定和支付代价。双倍是此版的两次结算状态，再创造双倍卡不会变成四次。两次之间会重新检查目标、剩余手牌及胜负状态。第一轮已结束比赛或卡已经离开棋盘，就不再继续下一轮。

数值型持续能力也翻倍，例如已激活的双倍赫卡提亚可计六分，双倍神奈子的增幅按四倍处理。覆盖权限、荒地放置权限、华扇的阵营替代身份等非数值规则仍按一个身份生效，不把同一张卡算成两张成员。纯持续能力的复制卡在放置时支付激活代价；双倍版本支付两份。复制恋自动上场也须支付额外代价，付不起时保留在手牌。卡牌与详情中显示复制、额外代价、双倍和燐的改写标识。

## AI 如何判断

以下说明主要对应困难 AI。简单、普通与困难的既有能力开关保留；难度决定它使用多少估值、线索、交易与后续规划，而不是允许它读取隐藏手牌。

### 1. 先判断结果，再比较效率

每张手牌都会枚举实际可用的棋盘位置，临时放到棋盘进行预览，然后恢复状态。比较时优先考虑本次能否获胜、是否存在不利结果、技能是否被禁用及是否应保留，之后比较可收取阵营、收益评分、手牌变化和位置。

主要评分来源包括立即收取的分数、技能直接得分或取牌收益、完成阵营的预计行动效率，以及少量铺设价值。后续阵营效率沿用“阵营预计分数 ÷ 预计还要付出的行动数”，并检查是否有足够材料及连通空间。分值是启发式比较尺度，**不是胜率，也不是已实现的分数**。

支付代价时继续估计被支付卡的保留价值；能完成阵营或近期能拿分的卡更难被当成代价。可选的昂贵技能会结合即时收益和破坏自身组牌的风险选择跳过。创造卡的额外代价也进入预算。

### 2. 美铃：评价推动后的局面，保留强制效果

AI 在实际可推动的候选中逐个模拟移动，比较自己的组牌潜力和对手公开的阵营威胁。当前推动评分为：

`自己的组牌价值变化 + 0.6 × 对手公开威胁减少量`

实际执行也使用这个比较结果。如果所有推动都不利，强制技能仍执行，并选择损失较小的合法推动；AI 会降低这种放置位置的优先级。规则本身没有增伤、额外移动或额外抽牌。

因此，“触发”“移动了卡牌”“有效改变状态”依然不等于赚到收益。第五张牌的阵营材料价值与技能质量分开判断，不能再用高触发率替它证明技能强。

### 3. 华扇：允许提前铺设，也计算被抢收的风险

AI 检查华扇附近的四卡阵营，结合正交相邻成员数和自己持有的该阵营牌给予小幅铺设分：

`min(0.95, 0.18 × 相邻成员数 + 0.20 × 自己手中的该阵营牌数) − 风险扣分`

若棋盘上该阵营已有至少三张，且已知对手持有该阵营牌，扣 0.65；只有未知风险则扣 0.18。没有永琳禁用时才计算这项技能铺设价值。它使“提前放置帮助自己完成四卡阵营”成为选择，也避免把马上送给对手收取的华扇当成好铺设。

### 4. 组合牌：有收益就释放，不无限等待最后一张

咲夜、辉夜、神奈子、小町、白莲仍可能因为未来组合被保留，但增加了具体释放条件：

- 神奈子：自己还有可合法放出的妖怪之山牌，可以考虑先用额外放置，而不只等最后一张。
- 辉夜：已有至少两张其他玩家的永远亭手牌线索，可考虑启动连猜。
- 小町：棋盘有另一张地狱牌，自己手里还有后续行动材料，可以考虑先放。
- 咲夜：剩余可作为代价的普通手牌较少（不超过三张），且技能估值大于 0.25，降低继续囤牌的倾向。
- 上述组合牌连续留在手牌至少三次自己的回合、且技能估值大于 0.25，也允许释放。**不是保留三回合就强制打出。**

荷取的技能铺设分改成很小的 0.12，主要仍靠山阵营本体价值获得位置。赫卡提亚沿用已有的条件式铺设判断。紫实际覆盖所得卡、覆盖前后组牌与威胁变化仍参与估值。

### 5. 觉与燐：按重制后得到的资源估值

觉在选目标玩家前，以公开的未知候选集合计算“随机看到至多四张后，最优一张的期望值”，扣掉付款损失，再给小幅信息价值。看到四张之后，只评价已经展示的牌；未展示牌按未知池的平均价值估算。若盲选期望高于可见最优牌超过 0.05，可以随机选一张背面牌。它不会遍历真实隐藏牌再挑最强的一张。

燐按“该卡技能已变成抽一张牌”的状态计算取回价值，再加从对手弃牌中移除的分数，或扣掉从自己弃牌取回造成的失分；接近胜利的对手被扣分的价值更高。这样不会因为看见旧版强技能就优先取它，也能重视重新取得阵营成员的价值。

### 6. 永琳、摩多罗：估计三选一的平均收益

永琳评估除永琳外的永远亭卡种；摩多罗评估除摩多罗外的公开棋盘合法候选。排除自身发生在三选一抽样之前，AI 的期望估值也使用相同过滤条件。只剩自身时，摩多罗不会打开无效选牌窗口，AI 也将创造收益记为零。AI 对每个候选估计阵营材料价值、粗略能力价值和复制后的付款负担，再计算随机抽选至多三张时选到最佳一张的期望值。实际看到三个候选后，选择其中评分最高的一张。

这部分是轻量启发式，尚未为每一种复制卡展开完整的后续对局搜索。额外代价按 0.22 的尺度进入创造候选评分，放置技能评分另计复制代价损失；双倍的收益和付款负担一同考虑。永琳还会根据自己手里的贤者和已知对手贤者，估计禁用带来的利弊。

### 7. 文：信息有权限，订阅有价格

AI 只在自己的正常行动阶段考虑订阅，且必须付款。订阅前的估值只读报纸元信息、公开的手牌数量与它已有的线索，不读取尚未购买的情报内容。

额外未知线索每项给予约 0.04 的基础估值；自己持有帕秋莉或辉夜时分别增加 0.45、0.65 的信息配合价值。付款成本包含被交出卡的取得价值；拆散自己的组牌加罚 4，交出的卡可能帮助文的玩家立刻凑齐阵营加罚 2。预期信息收益超过最便宜付款方案 0.15 才订阅。

因此，本版 AI 可能较少订阅，这是有付款门槛的结果。新增订阅计数与创造计数，方便新测试判断它是否过度保守。

### 8. 久侘歌与水蜜：比较本方机会成本

久侘歌在荒地上时按地狱材料取得来估值；普通位置则临时修改正交邻格荒地状态，比较可用空间、自己组牌潜力和公开威胁变化。放置前对牌堆目标的估计使用公开的可能候选，实际技能发动后才从合法地狱牌中选择。

水蜜优先封锁分数较高、手牌较多的对手，并扣除自己下一回合无法放置、无法交易的损失。自己的手牌仍有普通行动材料时扣约 0.55，否则扣约 0.10。目标的两回合限制不再被当成免费的纯收益。

## 信息、统计与稳定性

报纸的权限同时落实在日志渲染、手牌线索和联机快照。未订阅玩家收到的快照没有报纸卡名或真实卡编号；觉的背面牌通过临时匿名编号传给选牌界面。它们仍能选取，但不能从 DOM 属性或联机选择参数读出原卡。

创建卡与陷阱技能按稳定的原卡种标识汇总累计统计，单局追踪仍保留独立编号。这样不会在长时间测试中为每个复制编号永久增加一行统计。新导出包含规则版本；局面快照升版，保留复制卡与燐的改写信息，旧规则局面不能误导入新规则继续测。联机各端应使用同一份更新版游戏。历史残局保留当时的复制卡定义，重开后仍可解释其编号。

本版继承上一版的局内重开与清理：

- **N**：本局结束后开启下一局，默认不刷新整页。
- **P**：暂停或恢复 AI 测试。
- **D / F8**：打开测试数据，同时暂停；关闭数据不会自动恢复。
- 连续运行仍可单独开启，累计数据跨局保留。
- 重开释放旧对局、待处理回调、特效、以 WeakMap 跟踪的术语节点以及临时卡定义；快速渲染合并到同一帧，并保留 200 毫秒刷新节流。

## 平衡上的建议

1. 美铃继续定位为弱技能的第五成员。下一批测试重点看“通过香霖堂取得后是否帮助完成红魔馆”，不要以推动次数替代技能收益。
2. 永琳的新价值来自创造并立即打出，以及只压制贤者的战略作用。先测实际加速收取的频率与是否过度克制贤者，暂不叠加额外强化。
3. 摩多罗由立即复用变成延后使用复制，减少本回合直接爆发；但复制增加阵营材料，双倍技能仍有上限很高的选择。重点记录从创造到放置的等待，以及两次付款是否划算。
4. 燐应比较净失分、对手失分和之后重收阵营，而不再按照取回卡原有能力排名。保留阵营、统一抽一张牌是清晰且容易控制的方向。
5. 觉与文的价值依赖后续实际使用情报。分别看可见选牌与盲选、订阅付款与订阅后的成功猜测；单独的信息揭露次数不足以证明强度。
6. 华扇、久侘歌与水蜜的价值都依赖先后顺序。重点检查华扇提前铺设后的收取归属、久侘歌荒地分支与普通分支、水蜜封锁期间双方实际失去的行动。

## 验证范围

已执行实际 HTML 内的规则引擎、针对性规则检查、联机快照权限检查，以及模拟 DOM 控制检查。针对性规则与隐私检查共 63 项通过，模拟 DOM 控制检查共 13 项通过。12 局实际规则引擎测试覆盖 2、3、4 人与 4×4、5×5 的六种组合（每种两局），10 局获胜结束、2 局按僵局规则结束，运行错误与 600 回合上限中止均为零。1500 次重开检查是清理与控制压力测试，不是新规则下的 1500 局完整对局样本。

当前环境未完成真实浏览器中的动画、触摸拖拽和跨设备联机实测。上述测试能验证规则与快照内容，不能代替这些交互的视觉检查；本次小样本也不足以给重制卡建立可靠的胜率排行。

## 界面与创造限制补丁

规则标识更新为 `2026-10-12-create-news-v2`。觉的背面牌与主菜单背面牌共用太极卡背；每张背面牌保留选牌桌面需要的次序标签，修复标签缺失导致界面中断的问题。鼠标、触屏和键盘都可以盲选、取走及确认；双击、双击触屏和检查快捷键不会打开匿名牌的身份。
