# 妖怪之山关卡、累计星星与荒地规则

当前规则版本：`2026-10-16-story-kourindou-physics-v21`；保留 v20 评估局面导入兼容。

## 星星存档

- 保留“获胜才通关”的前提。每次获胜按完成的目标保存，重玩时合并不同目标；重复完成同一目标不增加星数。
- 多局累计三星仍显示普通星星。某一次获胜同时完成三个目标，才永久保存全星标记；关卡菜单中的星星使用本关介绍阵营的颜色；对局内按本局重新计算星星与目标；本局全星获胜同样着色。之后重玩不会失去该标记。
- 保存格式升级为版本 3，继续使用原来的存储键。旧版一星、二星保留原星数下限，不猜测它们对应的目标；旧版三星保留全部目标和全星标记。
- DEBUG 重置会同时清除目标、星数与全星标记，保留已通关状态和其他设置。

## 卡牌规则

| 卡牌 | 修改后的规则 |
| --- | --- |
| 洩矢诹访子 | 此卡在棋盘上且能力有效时，所有妖怪之山卡牌均可放在荒地上。原有的放置制造三块荒地保留。 |
| 八坂神奈子 | 移除自身可放在荒地上的能力。原有的加倍放置能力和从手牌放置妖怪之山卡牌保留。 |

权限按当前棋盘实时判断，也适用于妖怪之山第五张卡与复制卡。诹访子离场、能力被覆盖或被禁用后，权限立即消失。复制的诹访子须支付创造附加代价后才能提供被动；不会在付款前或拒绝付款后免费生效。没有其他有效诹访子时，诹访子自己不能先放到荒地。

普通 AI 的九个主要决策、评估、支付与交易函数没有修改；补充两个公共空间判断，让当前 AI 在诹访子生效时把荒地计入妖怪之山的连接路径和剩余空间。历史对照策略的内部代码保留。

## 第五关

先展示四张核心妖怪之山卡牌，沿用可拖动、点击查看、从旧到新恢复及阵营色光晕的介绍界面。技能开放范围为红魔馆、白玉楼、永远亭和妖怪之山。

| 项目 | 规则 |
| --- | --- |
| 通关 | 获胜；胜利不占用额外目标的位置。 |
| 星星一 | 玩家实际收取妖怪之山阵营。 |
| 星星二 | 对局实际进入所有玩家均无合法行动的僵局。 |
| 星星三 | 玩家实际付款订阅报纸后，通过帕秋莉或辉夜的真实技能正确猜中一次卡牌。 |
| 玩家开局 | 随机六张，包含神奈子与至少另一张妖怪之山卡牌。 |
| 电脑开局 | 随机六张，包含一张妖怪之山卡牌。 |
| 牌库 | 未发到任何玩家手中的核心妖怪之山卡牌，处于实际接下来五张抽牌内，位置随机。 |

发牌通过交换同一副真实卡牌实现，不复制、不丢牌，也不改变随机先手。第五关 AI 仍不知道玩家起始手牌。

第五关 AI 持有妖怪之山卡牌且有合法位置时，会立即优先打出，排在其他技能、抽牌和拖延之前。这个优先级同样适用于刚抽到或重新拿回的卡牌；持有多张时，按原有位置评分选择放置。

没有可放置的妖怪之山卡牌时，沿用第四关的简单模式基础技能评估：有实际价值、已解锁且不属于低优先级的技能优先；否则，在四张核心妖怪之山卡都曾上场前尽量通过合法的全员抽牌拖延。不能抽牌时照常选择放置或必要交易，不能为了拖延跳过有合法行动的回合。不能放置的封锁与铃仙的强制指令仍优先按规则结算。第五关 AI 仍不读取玩家未知手牌，第四关及普通 AI 不受这次优先级调整影响。

## 读报与僵局结算

付款订阅成功后直接显示情报，不再有额外的展开按钮。随后用猜牌技能猜中一次，即完成目标。仅生成自己的报纸、看见报纸、未成功付款或猜错均不算完成；订阅前猜中过也不能追溯计入。别人的未订阅报纸继续显示折起的封面，订阅须向记者支付一张手牌，报头与纸张样式保留。

故事模式僵局按弃牌分数结算，唯一最高分玩家获胜；并列不算玩家获胜。第五关因此可以在未达七分时，通过僵局胜利完成全部三项目标。普通模式的既有结算逻辑保留。

同时修复了故事模式隐藏商店后，空商店坐标仍被计入人类合法放置位置的问题：第一至五关的故事棋盘仅有主棋盘格；第六关按规则重新开放商店，避免虚假的合法行动阻止僵局。
