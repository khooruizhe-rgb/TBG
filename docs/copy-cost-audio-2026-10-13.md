# 双倍复制的代价、问号卡名与打印音效

摩多罗赋予复制卡双倍能力，代价保持单次。此前第二次结算再次调用付款，并把纯持续能力的创造附加代价乘二；本次改为在同一次技能发动里保存付款结果，第二次结算沿用它。此项修正于规则版本 `2026-10-13-single-cost-double-copy-v5` 引入；当前 v6 的摩多罗门槛及永琳 AI 跟进见 [后续修正](eirin-matara-2026-10-13.md)。

| 原技能 | 创造后支付 | 双倍效果 |
|---|---|---|
| 无代价抽一张牌 | 一张创造附加代价 | 抽两次，每次一张 |
| 代价 I | 代价 II，一次 | 结算两次 |
| 代价 III | 代价 IV，一次 | 结算两次 |
| 幽幽子的代价 N | N 加创造附加代价，一次 | 两次沿用同一个 N，受合法目标数量限制 |
| 纯持续能力、覆盖或恋的自动上场 | 一次创造附加代价 | 原有双倍数值或权限，不把代价再乘二 |

拒付第一次代价时，第二次不会免费生效。再次放置或再次发动时，会创建新的付款记录，仍需重新付一次。付款记录仅存在于这次结算，结束后恢复上层技能的上下文。

白莲的每个独立效果各自只付一次，第二次只重复第一次已经选择且成功付款、或本来免费的效果。即使第一次改变棋盘而使阵营减免消失，也不追加费用。鵺的双倍技能重复第一次选中的能力，沿用其付款结果。AI 初次判断仍使用恢复版策略；重复已付款效果时跳过再次付款的评估。

创造预览、手牌、棋盘、详情、日志和恢复后的复制卡名都使用原角色名加一个 `?`。再复制不会产生 `??`。英文、中文及全角问号输入均可规范化；问号不改变角色身份，原角色名仍可用于猜中复制卡。统计归类仍使用稳定的原卡 ID。

鵺详情里的 `Using XXX’s ability.` 现在翻译为“正在使用 XXX 的技能。”，其中角色名继续本地化，引用链接与中英文切换保留。

打印音效作为独立文件保存于 [audio/creation_print.mp3](../audio/creation_print.mp3)。原文件为用户提供的 `freesound_community-082499_thermal-receipt-print-amp-cut-48054.mp3`，共 50,991 字节，约 1.59 秒，未重新编码。游戏在打印开始时通过 GitHub URL 播放一次，不嵌入 Base64。静音、取消和重开会停止播放；快测不创建音频；音频加载失败或浏览器拒绝播放不会中断规则与动画。

后续指定卡牌 AI、匀速入手、时停渐变及紫/咲夜音效见 [针对性修正说明](secure-claims-tempo-2026-10-13.md)。

旧版 v4 的常规回合开始快照仍可导入，以当前规则继续，并恢复新的复制卡名；更早或不兼容的快照仍按原校验拒绝。
