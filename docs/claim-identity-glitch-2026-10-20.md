# 收取颜色、阵营场景与最终关故障

第十四关的桌面、棋盘区域、手牌区和面板由最近一次完整收取的阵营着色。永远亭采用蓝色，贤者采用紫色。领主放置保留原有落地声音和局部冲击，但不会切换最终关的背景或版面颜色。普通模式的领主背景保持原行为。

## 累计故障

最终关从实际收取事件累计卡牌张数：两卡阵营加二，四卡阵营加四；不同玩家、重复阵营及博丽神社都计算。部分结算只计实际进入弃牌区的张数，且不会切换完整阵营的配色。抽牌、付款、单纯放置、弃牌区后来减少，都不改变这个累计数。

累计数除以 160 得到视觉强度，上限为 1。随着强度增加，扫描线和错色条带更明显，撕裂位移从 2px 增至 26px，间歇故障周期从 14 秒缩短到 6 秒。超过 160 张仍累计计数，但不继续加大遮挡和运算量；棋盘达到 64 格也不停止累计。这是空间条带与错色，不是整屏亮灭。

颜色与故障状态只属于当前对局的展示层，不写入规则状态或 AI 输入。收取配色使用独立 CSS 属性，旧领主图片异步取色即使晚到也不能覆盖它。退出、重试会清除配色、故障、风化与待执行场景帧。

## 阵营区别

| 阵营 | 场景与运动 |
| --- | --- |
| 红魔馆 | 血红天空、红月；红雾位于整个游戏前方，取消中央透明遮罩，浓淡雾团横向流动，覆盖全屏。 |
| 白玉楼 | 远近多层密集暴雪、积雪、白色风幕。雪纹扩展到屏幕外，不旋转有限矩形；位移恰为纹理周期，循环无边界跳变。手机不再放慢雪速。 |
| 永远亭 | 月夜和满月；纸面泛白、干裂、磨损纹理从上往下覆盖实际版面，面板边框与棋盘内缘呈风化色。 |
| 妖怪之山 | 山体、山风；叶片横向翻滚掠过。 |
| 地灵殿 | 地底殿堂、巨眼和地热；余烬向上升起、消散。 |
| 贤者 | 黑紫间隙、会移动瞳孔并眨眼的眼睛，以及两侧开合的双扇门；手机四只眼睛，桌面六只。 |
| 博丽神社 | 最终关仍有对应配色和累计故障，保留上一种场景，没有专属满屏环境。 |
| 太阳花田 | 白金色烈阳、强烈日冕与光线、热浪；不再使用花田图片、巨大花盘或像素花。 |
| 地狱 | 改用四季映姬与庭渡久侘歌共用的彼岸背景 `--hell-higan-bg`，河流倒影与沿河漂移的灯火。 |
| 天界 | 天空、浮石与缓慢横移的大片云海，形状、色彩和运动均区别于红魔馆的雾。 |
| 命莲寺 | 保留命莲寺魔界背景和金色法环；符印围绕轨道运动。 |

背景、前景仍各保留两个切换槽；故障固定五层。场景只在收取事件时更新 DOM，不使用游戏随机数，也没有逐帧 JavaScript 循环、全屏截图或全屏背景滤镜。手机减少独立装饰数量，保留主要场景。减少动态效果时保留静态图案，关闭雪、眼睛、门、风化展开、故障和其他循环动画。

## 验证

十套定向回归共 317 项通过，其中本次新增 37 项：真实收取和领主事件、实际两卡与四卡结算、重复/跨玩家累计、博丽神社先收取、棋盘扩展到上限后的累计、十一种颜色、场景元素、减少动态效果、清理与迟到回调、普通模式行为。另复核了叠牌、支付、拖动、移动端手牌、全屏详情、原卡牌材质与最终关布局。

对 320×568、390×844、844×390、1920×1080、2560×1080 视口检查了雪层运动端点和中间位置的覆盖边界，以及纹理循环周期。规则区与 AI 策略区逐字保持原样，规则版本与摘要不变。

以上为受控 DOM、事件、CSS 结构及几何验证；没有进行浏览器像素或手机实机帧率验收。
