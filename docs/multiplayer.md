# TBG 联机版

这是当前完整贴图版，支持 **2–4 名玩家**，真人与电脑可以混合。每间房间有六位房间码。香霖堂保留三张商品；所有卡牌规则、拖拽选牌、语言选择与特效都使用当前版本。

## 开服与加入

1. 在开服电脑上安装 Node.js 20 或更新版本。
2. 将 `multiplayer-server.mjs` 与 `touhou_board_game_github_textures.html` 放在同一个文件夹。解压此包即可。
3. 在该文件夹打开终端，运行：

   ```sh
   node multiplayer-server.mjs
   ```

4. 开服电脑打开 `http://localhost:8787`。同一局域网的其他设备打开 `http://开服电脑的局域网IP:8787`，例如 `http://192.168.68.108:8787`。请保留 `http://` 和 `:8787`；只有 IP、不带端口会连接到其他端口。
5. 房主先在主界面选择人数、棋盘大小和电脑难度，再点击「联机」，填写名字，点击「创建房间」。将六位房间码告诉其他玩家。
6. 其他玩家打开同一个服务器地址，点击「联机」，填写名字和房间码，点击「加入房间」。
7. 房主可以点击「添加电脑玩家」填补空位。对局开始前，新加入的真人可以替换电脑座位。所有座位坐满，且真人都连接后，房主点击「开始联机对局」。

手机与电脑使用同一地址、同一房间码。每名玩家都会在自己的手牌区域进行交易、支付代价与技能选择，自己的座位显示在左下角。界面语言可以各自选择。

## 三档电脑难度

| 难度 | 掌握的策略 |
| --- | --- |
| 简单 | 基础放置、支付代价与收取当前阵营；不会交易。 |
| 中级 | 增加交易、即时收益与代价判断、根据公开棋盘阻止对手。 |
| 困难 | 保留当前完整策略，包括线索记忆、保留关键牌、凑牌与后续行动预判。 |

难度通过策略能力区分，不会随机故意犯错。技能规则本身的随机目标、猜牌与抽牌仍按规则执行。

## 不同网络的朋友

房间码不是服务器地址。所有人必须先连接到**同一台服务器**，才能使用其房间码。

朋友不在同一局域网时，可将服务器运行在可从互联网访问的主机上，并通过 HTTPS 反向代理提供访问；也可以使用连接各设备的私有网络/VPN。HTTPS 反向代理必须允许 `/api/events` 的持续连接，并关闭该路径的响应缓冲。

GitHub Pages 只能提供静态游戏页面，不能运行这个 Node.js 房间服务器。从静态页面点击「联机」后，可以填写已经运行的服务器地址，点击「打开服务器」，再创建或加入房间。

## 连接与对局

- 开服终端与房主游戏页面都需要保持开启：服务器转发消息，房主浏览器运行规则与电脑玩家。
- 其他玩家只会收到自己的手牌身份，其他手牌以数量显示；规则允许的窥视、公开与取牌选择按技能发送给对应玩家。
- 临时连接中断会自动重连，并重发该玩家的状态与尚未完成的选择。中断期间请保持页面开启。
- 房主刷新或关闭页面后，当前对局不能恢复。服务器重启也会清除房间。
- 非房主点击「主菜单」离开后，该座位由电脑继续。房主离开会关闭整个房间。
- 一局结束后，由房主点击「再来一局」，在原房间开始新对局。
- 直接打开 HTML 文件仍可进行单机游戏；联机需要上述服务器。

## `ERR_CONNECTION_REFUSED`

首先确认终端中显示服务器正在监听，然后确认访问地址包含正确端口 `:8787`。其他设备需要使用开服电脑的局域网 IP，不能使用 `localhost`。再确认设备能互相访问，且防火墙允许 TCP 8787。访客 Wi-Fi 的设备隔离也会阻止连接。

如果端口被占用，可更改：

macOS / Linux：

```sh
PORT=9000 node multiplayer-server.mjs
```

Windows PowerShell：

```powershell
$env:PORT=9000
node multiplayer-server.mjs
```

之后所有设备都使用新端口。

## 自动检查

包内有两组不需要浏览器的检查，都会自动启动临时服务器：

```sh
node multiplayer-smoke-test.mjs
node test-multiplayer-client.cjs
```

第一组检查 HTTP/SSE 房间、权限、真人与电脑加入、私有状态和重连消息。第二组将三个独立客户端接入真实服务器，检查当前引擎的交易、放置、抽牌、多张代价、选目标、白莲排序、铃仙强制幽幽子放置，以及同房间重开。这些检查验证规则与消息流程，不替代真实手机的画面与触控测试。
