# 创造始终使用原始卡牌

此规则于 `2026-10-14-original-creation-blueprints-v12` 引入。创造按角色最初的卡牌定义生成新牌，覆盖、其他创造牌与鵺的借用能力都不会改变创造原型。后续故事模式见 [v13 说明](story-opening-chapters-2026-10-15.md)。

| 来源的状态 | 新创造牌的结果 |
| --- | --- |
| 幽幽子被燐改成“覆盖：抽一张牌” | 原版幽幽子，使用代价 N 的收牌技能 |
| 鵺已选中咲夜或小町的能力 | 原版鵺，出场后重新选择自己的能力 |
| 来源是具有双倍能力的创造牌 | 原版角色；是否双倍由本次创造能力决定 |
| 来源已累计多个创造附加代价 | 新牌只增加一次代价 I |
| 场上有同角色的原件与多个创造牌 | 候选池只有该角色的一个原版候选 |

永琳仍创造具有双倍能力的永远亭牌并加入手牌。摩多罗仍在主棋盘至少四张牌时创造场上角色的普通复制并立刻打出；双方都不能创造自己。每张新牌使用独立 ID，原件不会被取走，名字只有一个问号，双倍能力的代价仍只支付一次。

这项规则只决定创造时的初始内容。旧牌已经受到的覆盖或借用效果保留；新创造牌以后受到燐的覆盖等技能时，也正常改变。v11 及此前已兼容版本的普通回合开始存档仍可导入，已有复制牌的技能、双倍效果和历史附加代价保持原状，从它们再创造的新牌使用原版规则。

## 候选与详情

候选牌使用缺墨打印外观、原角色名字、阵营、领主标记、原图与技能说明。候选不继承来源牌的破旧覆盖层、鵺的变幻外观、借用技能说明或场上的禁用灰色效果。选中前不生成实际新牌，选中后继续使用已有的打印、匀速入手和独立离场动画。

游戏内“创造”的解释仍为两句：从随机给出的三张指定类型卡牌中，选一张将其原版复制到手牌。创造牌的技能代价加 I。

## AI 的调整方法

AI 的创造估值先构造临时原版复制牌，计入本次的一次附加代价与永琳赋予的双倍效果，再使用原有的材料和收取评估。摩多罗的立刻放置预估也使用相同原型，并在去重后的角色池上计算三选一的保守得分；来源牌的覆盖、借用技能、双倍次数与旧代价不进入这次预测。

实际已经存在的复制牌仍按它目前的技能和代价预测放置。临时预估结束后还原定义、棋盘、手牌、激活状态和统计，不消耗随机数或提前执行技能。普通 AI 的主要决策与交易实现保持原样；本次只修正创造规则对应的候选与估值。
