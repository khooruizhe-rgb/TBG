# 最终关手牌与收取场景

## 固定顺序与叠牌

最终关的可见手牌按阵营顺序排列，阵营内按原始卡牌表的角色顺序排列，第五张卡归入自己的阵营。同种卡的重复实体叠成一摞，采用香霖堂的“×数量”标记和错开的纸边。桌面显示全部牌组；手机根据牌组数保留可见窗口和缓冲行。其他模式保持原有手牌展示。

每张卡仍有独立编号。显示排序不改写实际手牌数组、抽牌顺序或 AI 的判断。被覆盖的牌、创造牌、不同技能倍率或代价的牌分开叠放；付款时可选与不可选的实体也分开。铃仙指定的实体或已经选中的实体会成为那一摞的顶牌。

普通点击或拖动使用一张顶牌，数量在实际结算后减少。拖动和落地的飞行卡只显示这一张卡，数量标记留在原牌堆。涉及叠内其他实体的能力动画仍以可见牌堆为位置。

创造卡的入手动画会飞往相同能力的现有牌堆，或在固定排序中预留新牌的位置；飞行过程中刷新手牌也会保留该位置。

支付代价时，每点击一摞增加一张不同实体的选择，仍遵守本次付款上限；旁边显示已选数量，减号可以逐张取消。选中的牌堆沿用付款浮起效果。双击查看详情会恢复第一次点击前的付款选择。

## 收取后进入阵营场景

完整收取除博丽神社外的阵营时，天空完全替换为该阵营的环境，并出现巨型地标。场景在冠卡背景之后绘制，保留完整饱和度与不透明度。

另有位于游戏上方、不会拦截触控或点击的前景：浓雾、雪幕、裂隙、云海或魔界图像覆盖屏幕边缘，中央留出渐变空隙。收取瞬间会有约 1.9 秒的涌入动画，随后保持当前环境；连续收取切换到最后一个场景。

| 阵营 | 场景 |
| --- | --- |
| 红魔馆 | 血红天空、巨大红月与遮住边缘的浓雾 |
| 白玉楼 | 深蓝暴雪、积雪地形与横扫画面的白色雪幕 |
| 永远亭 | 月夜竹林、巨大满月与前景竹影 |
| 妖怪之山 | 山体剪影、山风、飞叶与绿色风幕 |
| 地灵殿 | 地底殿堂、巨眼、暗色立柱与红色地热 |
| 贤者 | 黑紫空间、带眼睛的巨大间隙与横穿边缘的裂口 |
| 太阳花田 | 真实花田、巨大金色花盘与前景向日葵 |
| 地狱 | 魔界底景、尖锐山体、火海与余烬 |
| 天界 | 天空、巨大浮石与覆盖边缘的云海 |
| 命莲寺 | 使用现有命莲寺魔界背景、巨大金色法环与前景魔界景象 |

背景和前景各有两个过渡槽，连续收取不会累积图层。手机最多四个粒子、桌面十二个，主要视觉量由大图层承担；循环运动使用 CSS 位移和透明度，不创建逐粒子的 JavaScript 更新。减少动态效果时保留静态场景并关闭涌入、飘动和粒子。重试、退出会清理两层场景及待处理帧。
